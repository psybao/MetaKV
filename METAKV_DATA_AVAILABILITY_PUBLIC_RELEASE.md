# Data availability wording

## BEFORE_UPLOAD

The data and code supporting the findings of this study have been prepared for public archival release. The final repository and DOI will be inserted prior to submission.

## AFTER_UPLOAD

The project-authored derived data and code supporting the findings of this study are publicly archived at GitHub ([GITHUB-URL]) and Zenodo ([ZENODO-DOI]). Third-party model weights and external HBM2 characterization resources are not redistributed and must be obtained from their original providers as documented in the archive.
