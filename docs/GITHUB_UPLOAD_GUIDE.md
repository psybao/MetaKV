- Topics: llm, kv-cache, quantization, reliability, fault-tolerance, gpu, metadata, low-precision

Upload the contents of `metakv-public-release` as the repository root. Verify SHA256SUMS.txt after checkout. Do not add model weights, tokens, private addresses, or the excluded HBM2 raw corpus. After creating the GitHub release, replace the placeholders in CITATION.cff and the availability statements, rebuild the archives, and rerun validation.
