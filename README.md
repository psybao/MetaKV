# MetaKV

**MetaKV: Fault-Resilient Structured Metadata for Low-Precision LLM KV Caches**

## Overview

Low-precision KV caches depend on compact scale metadata whose corruption can have disproportionate numerical impact. MetaKV introduces HA-FBMS, a same-width structured 32-bit log-scale representation, together with characterization-weighted logical metadata-bit mapping. Frozen experiments show bounded tested HA-FBMS amplification, corrected Binary32-Z comparisons, real-model scale evidence, and platform-dependent packed-kernel behavior.

## Key idea

HA-FBMS divides a calibrated log-scale interval into coarse thermometer-coded regions plus fine quantization. Logical metadata-bit mapping assigns encoded positions using empirical DDR and HBM2-derived weights. The mapping is a software layout over logical metadata bits, not a physical HBM lane-placement mechanism.

## What this repository contains

- CPU reference codecs for HA-FBMS, corrected Binary32-Z, and FP32
- logical fault screening and bit-mapping utilities
- final experiment scripts selected by the authoritative path and supersession registries
- processed paper numbers, table sources, figure data, and publication figures
- provenance, hashes, environment notes, and layered reproduction instructions

## What this repository does not contain

- no model weights or Hugging Face snapshots
- no third-party hardware-fault corpus
- no hardware BER measurements generated by this study
- no physical HBM lane placement
- no claim of full end-to-end generation benchmarking
- no Python environments, credentials, caches, or private address
